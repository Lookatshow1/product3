## Экран 1: Онбординг (первый вход)

**URL:** `/onboarding`

**Шаги:**
1. **Приветствие** — "CallFlow OS покажет, сколько денег теряет ваша клиника. Старт за 10 минут."
2. **Данные о клинике:**
   - Название клиники
   - Тип (стоматология / косметология / многопрофильная / другое)
   - Кол-во кресел/кабинетов (число)
   - Средний чек (₽) — подсказка: "Обычно 5 000–12 000 ₽ для стоматологии"
   - Часовой пояс
3. **Первый импорт** — выбор:
   - [Загрузить CSV/Excel] — "Если есть выгрузка из АТС или CRM"
   - [Ввести вручную] — "5 чисел за 30 секунд"
   - [Использовать демо-данные] — "Посмотреть, как работает, на примере"
4. **Готово** — "Ваш первый отчёт готов! →" (переход на дашборд)

**Пустое состояние:** Нет — онбординг всегда ведёт к данным (хотя бы демо).

**Ошибки:**
- Файл не распознан → "Формат файла не поддерживается. Скачайте шаблон →"
- Файл пустой → "Файл не содержит данных. Проверьте файл или введите данные вручную"

## Экран 8: Настройки

**URL:** `/settings`

**Подразделы:**

### 8a. Клиника (`/settings/clinic`)
- Название, тип, адрес
- Часовой пояс
- Логотип (для PDF)
- Средний чек (₽)
- Рабочие часы (для расчёта пропущенных "в рабочее время")

### 8b. Пользователи (`/settings/users`)
- Таблица пользователей: имя, email, роль, статус, последний вход
- [+ Пригласить пользователя] → email + роль
- Редактирование роли
- Деактивация

### 8c. Уведомления (`/settings/notifications`)
- Email дайджесты: вкл/выкл для каждого (08:30, 12:30, 20:30)
- Время отправки (настраиваемое)
- Получатели
- Web-push: вкл/выкл
- Триггеры алертов

### 8d. Коэффициенты (`/settings/benchmarks`)
- Средний чек (₽): [8 500]
- Целевой % принятых: [90]
- Целевая конверсия в запись: [55]
- Целевая доходимость: [85]
- Средняя маржинальность: [60%]
- [Сбросить к отраслевым дефолтам]

### 8e. Данные и приватность (`/settings/privacy`)
- Режим: ○ Обезличенный (по умолчанию) ○ С персональными данными
- При переключении на "персональный": чекбокс подтверждения + текст согласия
- [🗑 Удалить все данные клиники] — с подтверждением (ввод названия клиники)
- [📥 Экспорт всех данных] — GDPR-compliant
- Политика хранения аудио: [90 дней ▼]

## Глобальные UI-элементы

**Хедер:**
```
[🏥 Название клиники ▼] [Филиал ▼]    [🔔 3] [👤 Иванов И. ▼ → Профиль / Выход]
```

**Sidebar:**
- Иконки + текст
- Collapse mode (только иконки) на мобильных
- Активный пункт подсвечен
- Бейджи: количество задач на "План дня", непрочитанные на "Уведомления"

**Общие состояния:**
- Loading: скелетон-анимация (не спиннер)
- Error: красная плашка с текстом + кнопка "Повторить"
- Empty: иллюстрация + текст + CTA
- Success: зелёная плашка с автоскрытием через 5 сек

**Цветовая схема:**
- Primary: #2563EB (синий — доверие, медицина)
- Danger/Loss: #DC2626 (красный — потери)
- Success/Recovery: #16A34A (зелёный — возвращённые деньги)
- Warning: #F59E0B (жёлтый — внимание)
- Neutral: #6B7280 (серый)
- Background: #F9FAFB
