# CallFlow OS — One-Pager для разработки: Sprint 1 (2 недели до продажи)

## Цель спринта
Через 2 недели: пользователь регистрируется → загружает CSV или вбивает 5 чисел → видит потери в рублях + план задач на день. Можно показывать клиентам и продавать.

---

## Команда
- 2 fullstack-разработчика (Next.js + NestJS)
- 1 дизайнер (первые 3 дня — макеты ключевых экранов, далее по ходу)

## Стек
- Next.js 14 (App Router) + TypeScript + Tailwind + shadcn/ui
- NestJS + Prisma + PostgreSQL 16
- BullMQ + Redis
- Docker Compose (dev + staging)

## Ключевые технические решения (зафиксировать до старта)

1. **Монорепо или раздельные репо?** → Монорепо (Turborepo): `apps/web` (Next.js) + `apps/api` (NestJS) + `packages/shared` (types, utils)
2. **Prisma или TypeORM?** → Prisma (type-safety, миграции, studio)
3. **Где хранить JWT?** → HttpOnly cookie (refresh) + memory (access)
4. **Как считать потери: на лету или кэш?** → Кэш в `daily_losses` таблице, пересчёт после каждого импорта (BullMQ job)
5. **CSV парсинг: клиент или сервер?** → Превью на клиенте (Papa Parse), полный парсинг на сервере
6. **Часовые пояса** → Всё в UTC в БД, преобразование в TZ клиники в API/UI
7. **Формат API** → REST JSON. GraphQL не нужен на MVP.
